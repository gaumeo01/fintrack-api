# Finance Tracker Frontend

React + TypeScript + Vite app for the Finance Tracker API.

## Run Locally

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Set `VITE_API_BASE_URL` to the backend origin, for example:

```text
VITE_API_BASE_URL=http://localhost:8080
```

Build for production:

```bash
npm run build
```
